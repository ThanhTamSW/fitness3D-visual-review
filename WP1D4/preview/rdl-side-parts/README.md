This folder holds a **pre-WP1D.5 render** and is kept only for history.

The side camera for this image was placed at azimuth 90, which looks **down the
anterior axis (-Y)**: it is a **posterior view**, not a sagittal one. The
anterior/posterior labels burned into it are therefore meaningless, and the hip
hinge cannot be judged from this angle.

Measured provenance: this folder's image matches the pre-fix
`rdl_side_sheet.png` at 45.35 dB PSNR and the corrected sagittal sheet at
13.09 dB. It is the old picture.
